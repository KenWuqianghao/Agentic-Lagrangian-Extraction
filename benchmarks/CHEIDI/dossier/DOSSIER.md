## Lagrangian

Define the real scalar mode tower
\[
S(x)\equiv \sum_{k=1}^{10}\xi_k\,Hh_k(x),
\]
where `Hh[k]` is implemented as the class members `Hh1` through `Hh10`.

The new fields `Hh_k` have no declared SM gauge quantum numbers. Their covariant derivative is therefore just
\[
D_\mu Hh_k=\partial_\mu Hh_k .
\]
For SM fields appearing implicitly through `LSM`, the usual SM covariant derivative is understood:
\[
D_\mu=\partial_\mu
+i g_s\,T^a G^a_\mu
+i g\,\frac{\tau^I}{2}W^I_\mu
+i g'Y B_\mu ,
\]
with the relevant representation matrices omitted for gauge-singlet fields.

### `LHEIDI`

The file defines
\[
\texttt{LHEIDI}
=
\left.\mathcal L_{\rm SM}\right|_{\mu_H\to 0,\ \lambda\to 0,\ H\to S}.
\]

The new-field-dependent part is therefore the SM Higgs interaction structure with the physical Higgs field replaced by \(S=\sum_k\xi_k Hh_k\), while the Higgs potential terms proportional to `muH` and `\[Lambda]` are removed.

Scalar kinetic term:
\[
\boxed{
\mathcal L_{\texttt{LHEIDI}}
\supset
\frac12\,\partial_\mu S\,\partial^\mu S
=
\frac12
\sum_{k,\ell=1}^{10}
\xi_k\xi_\ell\,
\partial_\mu Hh_k\,\partial^\mu Hh_\ell
}
\]

Gauge-boson mass-interaction terms:
\[
\boxed{
\mathcal L_{\texttt{LHEIDI}}
\supset
\frac{2M_W^2}{v}\,
S\,W^+_\mu W^{-\mu}
}
\]

\[
\boxed{
\mathcal L_{\texttt{LHEIDI}}
\supset
\frac{M_W^2}{v^2}\,
S^2\,W^+_\mu W^{-\mu}
}
\]

\[
\boxed{
\mathcal L_{\texttt{LHEIDI}}
\supset
\frac{M_Z^2}{v}\,
S\,Z_\mu Z^\mu
}
\]

\[
\boxed{
\mathcal L_{\texttt{LHEIDI}}
\supset
\frac{M_Z^2}{2v^2}\,
S^2\,Z_\mu Z^\mu
}
\]

Fermion Yukawa terms:
\[
\boxed{
\mathcal L_{\texttt{LHEIDI}}
\supset
-\sum_{i}
\frac{m_{u_i}}{v}\,
S\,\bar u_i u_i
}
\]

\[
\boxed{
\mathcal L_{\texttt{LHEIDI}}
\supset
-\sum_{i}
\frac{m_{d_i}}{v}\,
S\,\bar d_i d_i
}
\]

\[
\boxed{
\mathcal L_{\texttt{LHEIDI}}
\supset
-\sum_{i}
\frac{m_{\ell_i}}{v}\,
S\,\bar\ell_i \ell_i
}
\]

Equivalently, in chiral-projector notation,
\[
\bar f f
=
\bar f_L f_R+\bar f_R f_L
=
\bar f\,P_R f+\bar f\,P_L f,
\qquad
P_{R,L}=\frac{1\pm\gamma^5}{2}.
\]

The file removes the SM Higgs potential through
\[
\mu_H\to 0,\qquad \lambda\to 0,
\]
so no \(S\), \(S^2\), \(S^3\), or \(S^4\) potential terms are generated by `LHEIDI`.

### `LHEIDIgg`

The file also defines a finite-top-mass effective scalar-gluon-gluon interaction:
\[
\boxed{
\mathcal L_{\texttt{LHEIDIgg}}
=
\sum_{k=1}^{10}
\frac{\sqrt{K_{ggh}}\,g_s^2}{32\pi^2 v}\,
F(\tau_k)\,
\xi_k\,Hh_k\,
\left(
\partial_\nu G^a_\mu-\partial_\mu G^a_\nu
\right)
\left(
\partial^\nu G^{a\mu}-\partial^\mu G^{a\nu}
\right)
}
\]

with
\[
\tau_k=\frac{4M_T^2}{m_{Hh_k}^2},
\]
and the loop form factor as encoded in the file:
\[
F(\tau)
=
\tau\left[
1+(1-\tau)\,f(\tau)
\right],
\]
where
\[
f(\tau)=
\begin{cases}
\arcsin^2\!\left(\sqrt{1/\tau}\right),
& \text{if } \tau>1,\\[6pt]
-\dfrac14
\left[
\log\!\left(
\dfrac{1+\sqrt{1+\tau}}{1-\sqrt{1-\tau}}
\right)
-i\pi
\right]^2,
& \text{otherwise.}
\end{cases}
\]

Here \(G^a_\mu\) is the gluon field. The `.fr` expression uses only the Abelianized derivative combination \(\partial_\nu G^a_\mu-\partial_\mu G^a_\nu\), not the full non-Abelian field strength
\[
G^a_{\mu\nu}
=
\partial_\mu G^a_\nu-\partial_\nu G^a_\mu
+g_s f^{abc}G^b_\mu G^c_\nu .
\]

### `LHEIDIggHeavyTop`

The heavy-top limit replaces \(F(\tau_k)\to 2/3\):
\[
\boxed{
\mathcal L_{\texttt{LHEIDIggHeavyTop}}
=
\sum_{k=1}^{10}
\frac{\sqrt{K_{ggh}}\,g_s^2}{32\pi^2 v}\,
\frac{2}{3}\,
\xi_k\,Hh_k\,
\left(
\partial_\nu G^a_\mu-\partial_\mu G^a_\nu
\right)
\left(
\partial^\nu G^{a\mu}-\partial^\mu G^{a\nu}
\right)
}
\]

Equivalently,
\[
\boxed{
\mathcal L_{\texttt{LHEIDIggHeavyTop}}
=
\sum_{k=1}^{10}
\frac{\sqrt{K_{ggh}}\,g_s^2}{48\pi^2 v}\,
\xi_k\,Hh_k\,
G^a_{\mu\nu,\mathrm{lin}}G^{a\mu\nu}_{\mathrm{lin}}
}
\]
with
\[
G^a_{\mu\nu,\mathrm{lin}}
=
\partial_\mu G^a_\nu-\partial_\nu G^a_\mu .
\]

### `LTot`

The total Lagrangian exported by the file is
\[
\boxed{
\mathcal L_{\texttt{LTot}}
=
\mathcal L_{\texttt{LHEIDIggHeavyTop}}
}
\]

so the active `LTot` contains only the heavy-top effective scalar-gluon-gluon interaction, not the full `LHEIDI` expression.

## Physics Summary

The file encodes ten real gauge-singlet scalar modes `Hh1` through `Hh10` that couple to Standard-Model fields through Higgs-like mixing coefficients \(\xi_k\). The only active total Lagrangian, `LTot`, keeps the heavy-top effective coupling of these scalars to two gluons, so it mediates gluon-fusion production \(gg\to Hh_k\) and the crossed decay \(Hh_k\to gg\).

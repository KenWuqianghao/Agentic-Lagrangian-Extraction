## Physics content of arXiv:1106.6199

Eq. (1) is an effective, mass-eigenstate Lagrangian (written after electroweak symmetry breaking). It adds six new states:

| paper symbol | spin | colour | Q | role | benchmark mass |
|---|---|---|---|---|---|
| φ | 0 | singlet | 0 | invisible scalar (FCNC production) | 300 GeV (Scen. III) |
| V | 1 | singlet | 0 | invisible vector (FCNC production) | 50 GeV (Scen. IV) |
| χ | 1/2 | singlet | 0 | invisible fermion | 50 GeV (Scen. I) |
| ϕ | 0 | triplet | +2/3 | resonant scalar (`ϕ → t χ`) | 500 GeV |
| ϕ̃ | 0 | triplet | −1/3 | heavy scalar, 4-fermion limit | 3000 GeV |
| X | 1 | triplet | +2/3 | resonant vector (`X → t χ`) | 500 GeV |

Charges are re-derived from the operators, not copied: `ε_ijk ϕ_i d̄^c_j Γ d_k` fixes Q(ϕ) = +2/3, and `ϕ_i ū_i Γ χ` gives the same value with Q(χ) = 0. The same two checks give Q(ϕ̃) = −1/3 and Q(X) = +2/3. Each new coloured state is an SU(2)_L singlet, so Y = Q. All coloured fields carry `Index[Colour]`, so `DC[]` gives their QCD (and photon/Z) couplings. No new index is needed: only `Colour` and `Generation` appear.

The paper has no explicit `1/Λ^n` operator — the four-fermion limit is generated by the propagator of the 3 TeV ϕ̃ field, so no EFT cutoff parameter is declared.

Notes on the table:
- Every new class has its kinetic + mass row above, and every kinetic term is in `LKinMT`, which is in the total sum `LMonotop`.
- Hypercharge: Eq. (1) uses Dirac mass eigenstates `uq`, `dq` with both chiralities, so Y is not a good quantum number term by term; the paper's Lagrangian is written in the broken phase. The U(1)_em sum is 0 for every term, and each new field gets Y = Q because it is an SU(2)_L singlet. The `a` and `b` couplings would split into pure-chirality pieces in an unbroken-phase version.
- `SelfConjugate -> True` classes: `phiv` and `vecv`. Both carry no `QuantumNumbers`.
- Baryon number: the paper calls these interactions baryon-number violating, so no B or L quantum number is declared.
- Charge conjugation: the three `d̄^c` operators use `CC[dqbar[...]]`, the FeynRules form of the barred charge-conjugate field, with the class field `dq` and its `Generation` index.

## Physics content of arXiv:1106.6199

Eq. (1) is an effective, mass-eigenstate Lagrangian (written after electroweak symmetry breaking). It adds six new states:

| paper symbol | spin | colour | Q | role | benchmark mass |
|---|---|---|---|---|---|
| φ | 0 | singlet | 0 | invisible scalar (FCNC production) | 300 GeV (Scen. III) |
| V | 1 | singlet | 0 | invisible vector (FCNC production) | 50 GeV (Scen. IV) |
| χ | 1/2 | singlet | 0 | invisible fermion | 50 GeV (Scen. I) |
| ϕ | 0 | triplet | +2/3 | resonant scalar (`ϕ → t χ`) | 500 GeV |
| ϕ̃ | 0 | triplet | −1/3 | heavy scalar, 4-fermion limit | 3000 GeV |
| X | 1 | triplet | +2/3 | resonant vector (`X → t χ`) | 500 GeV |

Charges are re-derived from the operators, not copied: `ε_ijk ϕ_i d̄^c_j Γ d_k` fixes Q(ϕ) = +2/3, and `ϕ_i ū_i Γ χ` gives the same value with Q(χ) = 0. The same two checks give Q(ϕ̃) = −1/3 and Q(X) = +2/3. Each new coloured state is an SU(2)_L singlet, so Y = Q. All coloured fields carry `Index[Colour]`, so `DC[]` gives their QCD (and photon/Z) couplings. No new index is needed: only `Colour` and `Generation` appear.

The paper has no explicit `1/Λ^n` operator — the four-fermion limit is generated by the propagator of the 3 TeV ϕ̃ field, so no EFT cutoff parameter is declared.

- Every new class has its kinetic + mass row above, and every kinetic term is in `LKinMT`, which is in the total sum `LMonotop`.
- Hypercharge: Eq. (1) uses Dirac mass eigenstates `uq`, `dq` with both chiralities, so Y is not a good quantum number term by term; the paper's Lagrangian is written in the broken phase. The U(1)_em sum is 0 for every term, and each new field gets Y = Q because it is an SU(2)_L singlet. The `a` and `b` couplings would split into pure-chirality pieces in an unbroken-phase version.
- `SelfConjugate -> True` classes: `phiv` and `vecv`. Both carry no `QuantumNumbers`.
- Baryon number: the paper calls these interactions baryon-number violating, so no B or L quantum number is declared.
- Charge conjugation: the three `d̄^c` operators use `CC[dqbar[...]]`, the FeynRules form of the barred charge-conjugate field, with the class field `dq` and its `Generation` index.

Finding 1 · Top-Philic Z′

The model was right; the label was wrong

Problem

  • Crosscheck row said extra-in-reconstruction
  • It meant "the paper omits it"; it read as "the model lacks it"

Approach

  • Rename verdicts: in-paper-not-in-model / in-model-not-in-paper
  • Tag standard free-field completions as such
  • Prompt rule: named kinetic + mass term for every new field

Result

  • Shipped in heptapod-dev #16
  • 4 / 4 reruns carry the terms; all 4 pass the full compile chain

Finding 2 · EffLRSM

ψc was dropped on the WR current

Problem

  • bar[ve].Ga[mu].ProjP.l WR conserves lepton number
  • Eq. (5) has ν̄c: ΔL = 2, as a Majorana ν requires

Approach

  • Prompt rule: CC[] wherever the paper writes ψc
  • Accept the reference's choice too: drop the term (X = 0)

Result

  • 4 / 4 reruns resolve it (bar[CC[vl]] or dropped)
  • CC[] compiles: proven in 368 sextets v2/s1

Finding 3 · General U(1)

A missing Eps and a copied sign

Problem

  • LLbar[..,ii] Phibar[ii] is not an SU(2) singlet
  • -xH/2 copied from Table I; Eq. (1) uses another Y(H) convention
  • Only +xH/2 keeps all five Yukawas invariant

Approach

  • Rule: Eps[ii,jj] for any two same-type doublets
  • Rule: derive every U(1) charge from Yukawa invariance; never copy a table
  • Mandatory self-audit: Q, Y, X sums per term

Result

  • Eps: 4 / 4 reruns
  • Sign: original prompt 1 / 2 → addendum 2 / 2, derivation written in the file

The prompt addendum

Six rules and a self-audit

  • Kinetic + mass term for every new field, named and summed
  • Every operator of dimension d carries 1/Lam^(d-4), cutoffs External
  • CC[] wherever the paper writes ψc
  • Eps[i,j] for any two same-type doublets
  • U(1) charges re-derived from Yukawa invariance, never copied
  • Read only the paper
  • Then a table per term: mass dimension, coupling dimension, Q / Y / X sums

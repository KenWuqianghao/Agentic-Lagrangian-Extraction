# Reconstruction of `sanitized.fr`

## 0. Conventions used below

The file declares no gauge group of its own and ends with

```
LTotal := LSM + LWRkin + LZRkin + LNkin + LWRq + LWRl + LZRq + LZRl;
```

so it is an **add-on module on top of the standard FeynRules Standard Model file**. All
Standard Model symbols are inherited from that file:

| `.fr` symbol | meaning |
| --- | --- |
| `uq`, `dq` | SM quark fields $u$, $d$ (3 generations, colour triplets) |
| `l`, `vl` | SM charged lepton $\ell$ and light neutrino $\nu_L$ |
| `gw` | $SU(2)_L$ gauge coupling $g_L$ |
| `sw`, `cw` | $\sin\theta_W$, $\cos\theta_W$ |

FeynRules idioms are expanded as follows.

* `Ga[mu]` $\to \gamma^\mu$.
* `ProjP` $\to P_R=\tfrac12(1+\gamma_5)$, `ProjM` $\to P_L=\tfrac12(1-\gamma_5)$.
* `FS[V,mu,nu]` for a field with **no gauge index** is the abelian field strength
  $V_{\mu\nu}=\partial_\mu V_\nu-\partial_\nu V_\mu$. There is no non-abelian
  self-interaction and no $\gamma$/$Z$/$W$ mixing vertex generated by these terms.
* `del[X,mu]` $\to \partial_\mu$.
* `HC[tmp]` $\to$ the hermitian conjugate of the preceding expression, $+\,\mathrm{h.c.}$
* `Xbar` $\to \bar X$.

**Covariant derivative.** The file uses **no** `DC` anywhere. The two new vectors $W_R$
and $Z_R$ and the new fermion $N_R$ have **plain partial derivatives** only
($\partial_\mu$, see `LNkin`, `LWRkin`, `LZRkin`). The new states are therefore
**not** gauged in this file: $W_R$ and $Z_R$ enter as massive vector fields with
hand-written currents, and $N_R$ is an $SU(3)_c\times SU(2)_L\times U(1)_Y$ singlet with a
bare Majorana mass. The only covariant derivatives in the full model are the Standard
Model ones inside `LSM`, with gauge content
$SU(3)_c\times SU(2)_L\times U(1)_Y$,
$D_\mu = \partial_\mu - i g_s T^a G^a_\mu - i g_L T^i W^i_\mu - i g' Y B_\mu$.
This is an **effective / phenomenological** $W_R$–$Z_R$ Lagrangian, not a full
left–right gauge model.

Note also: the file contains **no** `CC` (charge-conjugation) operator anywhere, even
though `NR` is declared `SelfConjugate -> True`. See §5.

## 1. Lagrangian, term by term

### 1.1 `LWRkin` — kinetic and mass term of the charged heavy vector

`LWRkin := -1/2 FS[WRbar,mu,nu] FS[WR,mu,nu] + MWR^2 WRbar[mu] WR[mu]`

$$
\mathcal{L}_{W_R}^{\rm kin}\;=\;-\frac{1}{2}\,W_{R\,\mu\nu}^{\dagger}\,W_R^{\mu\nu}
\;+\;M_{W_R}^{2}\,W_{R\,\mu}^{\dagger}\,W_R^{\mu},
\qquad
W_{R\,\mu\nu}=\partial_\mu W_{R\,\nu}-\partial_\nu W_{R\,\mu}.
$$

$W_R$ is complex, so the normalisation is $-\tfrac12|W_{\mu\nu}|^2 + M^2|W_\mu|^2$
(the usual complex-vector normalisation, not the $-\tfrac14,\ \tfrac12 M^2$ real one).

### 1.2 `LZRkin` — kinetic and mass term of the neutral heavy vector

`LZRkin := -1/4 FS[ZR,mu,nu] FS[ZR,mu,nu] + 1/2 MZR^2 ZR[mu] ZR[mu]`

$$
\mathcal{L}_{Z_R}^{\rm kin}\;=\;-\frac{1}{4}\,Z_{R\,\mu\nu}Z_R^{\mu\nu}
\;+\;\frac{1}{2}M_{Z_R}^{2}\,Z_{R\,\mu}Z_R^{\mu},
\qquad
Z_{R\,\mu\nu}=\partial_\mu Z_{R\,\nu}-\partial_\nu Z_{R\,\mu}.
$$

$Z_R$ is real (self-conjugate), hence the $-\tfrac14$, $+\tfrac12 M^2$ normalisation.

### 1.3 `LNkin` — Majorana kinetic and mass term of the heavy neutrinos

`LNkin := I/2 NRbar.Ga[mu].del[NR,mu] - 1/2 MN[ff] NRbar[sp,ff].NR[sp,ff]`

$$
\mathcal{L}_{N}^{\rm kin}\;=\;\frac{i}{2}\sum_{f=1}^{3}\bar N_f\,\gamma^\mu\,\partial_\mu N_f
\;-\;\frac{1}{2}\sum_{f=1}^{3} M_{N_f}\,\bar N_f N_f .
$$

The factors of $\tfrac12$ are the Majorana normalisation. The mass matrix `MN[ff]` is
**diagonal in generation space** by construction (the mass is declared per class member),
so $N_1,N_2,N_3$ are the mass eigenstates. The generation index `ff` is summed; `sp` is
the (summed) spinor index.

### 1.4 `LWRq` — right-handed charged quark current

```
tmp = -(kapRq gw/Sqrt[2]) uqbar.VCKMR.Ga[mu].ProjP.dq WR[mu];
LWRq = tmp + HC[tmp]
```

$$
\mathcal{L}_{W_R}^{q}\;=\;
-\frac{\kappa_R^{\,q}\,g_L}{\sqrt{2}}\;
\bar u_i\,\bigl(V^{R}_{\rm CKM}\bigr)_{ij}\,\gamma^\mu P_R\, d_j\; W_{R\,\mu}
\;+\;\mathrm{h.c.}
$$

expanded, the hermitian conjugate is

$$
\mathrm{h.c.}=-\frac{\kappa_R^{\,q}\,g_L}{\sqrt{2}}\;
\bar d_j\,\bigl(V^{R\,\dagger}_{\rm CKM}\bigr)_{ji}\,\gamma^\mu P_R\, u_i\; W_{R\,\mu}^{\dagger}.
$$

Index contraction: $i,j$ are generation indices ($i$ on the up-type field, $j$ on the
down-type field); colour is contracted diagonally inside each bilinear (inherited from
`uq`, `dq`). The projector is $P_R$ on **both** the quark and its conjugate, i.e. a pure
$V+A$ current. Writing $g_R \equiv \kappa_R^{\,q} g_L$ makes the structure the familiar
right-handed charged current.

### 1.5 `LWRl` — right-handed charged lepton current

```
tmp = -(kapRl gw/Sqrt[2]) ( NRbar.YN.Ga[mu].ProjP.l + vlbar.XN.Ga[mu].ProjP.l ) WR[mu];
LWRl = tmp + HC[tmp]
```

$$
\mathcal{L}_{W_R}^{\ell}\;=\;
-\frac{\kappa_R^{\,\ell}\,g_L}{\sqrt{2}}
\Bigl[\;
\bar N_i\,(Y_N)_{ij}\,\gamma^\mu P_R\,\ell_j
\;+\;
\bar\nu_{i}\,(X_N)_{ij}\,\gamma^\mu P_R\,\ell_j
\;\Bigr] W_{R\,\mu}
\;+\;\mathrm{h.c.}
$$

with the hermitian conjugate

$$
\mathrm{h.c.}=-\frac{\kappa_R^{\,\ell}\,g_L}{\sqrt{2}}
\Bigl[\;
\bar\ell_j\,(Y_N^{\dagger})_{ji}\,\gamma^\mu P_R\,N_i
\;+\;
\bar\ell_j\,(X_N^{\dagger})_{ji}\,\gamma^\mu P_R\,\nu_i
\;\Bigr] W_{R\,\mu}^{\dagger}.
$$

Points of precision:

* Both pieces carry $P_R$, so the **charged lepton is right-handed** in both.
* $Y_N$ is the heavy-neutrino mixing matrix (heavy $N$ with a right-handed $\ell$);
  $X_N$ is the light-neutrino mixing matrix (light $\nu$ with a right-handed $\ell$),
  i.e. the light–heavy mixing leak. $X_N$ is set to **zero** numerically, so the second
  piece gives no vertex at the default point.
* Since $N$ is Majorana, $\bar N \gamma^\mu P_R \ell$ and its conjugate together give
  **both** $N\ell^- W_R^+$ and $N\ell^+ W_R^-$ vertices — the lepton-number-violating
  pair. No explicit `CC` is used to build them.

### 1.6 `LZRq` — neutral heavy-vector quark current

```
LZRq := -(kapRq gw/nZRq) ( gLZRu uqbar.Ga[mu].ProjM.uq + gRZRu uqbar.Ga[mu].ProjP.uq
                         + gLZRd dqbar.Ga[mu].ProjM.dq + gRZRd dqbar.Ga[mu].ProjP.dq ) ZR[mu]
```

$$
\mathcal{L}_{Z_R}^{q}\;=\;
-\frac{\kappa_R^{\,q}\,g_L}{n_{Z_R}^{\,q}}\;
\Bigl[\;
g^{u}_{L}\,\bar u\gamma^\mu P_L u+g^{u}_{R}\,\bar u\gamma^\mu P_R u
+g^{d}_{L}\,\bar d\gamma^\mu P_L d+g^{d}_{R}\,\bar d\gamma^\mu P_R d
\;\Bigr] Z_{R\,\mu}.
$$

The current is **flavour diagonal** (no generation matrix appears): generation and colour
are contracted inside each bilinear. This term is already hermitian; no `HC` is added.

### 1.7 `LZRl` — neutral heavy-vector lepton current

```
LZRl := -(kapRl gw/nZRl) ( gLZRe lbar.Ga[mu].ProjM.l + gRZRe lbar.Ga[mu].ProjP.l
                         + gLZRv vlbar.Ga[mu].ProjM.vl
                         + gRZRn NRbar.Ga[mu].ProjP.NR ) ZR[mu]
```

$$
\mathcal{L}_{Z_R}^{\ell}\;=\;
-\frac{\kappa_R^{\,\ell}\,g_L}{n_{Z_R}^{\,\ell}}\;
\Bigl[\;
g^{e}_{L}\,\bar\ell\gamma^\mu P_L \ell+g^{e}_{R}\,\bar\ell\gamma^\mu P_R \ell
+g^{\nu}_{L}\,\bar\nu\gamma^\mu P_L \nu
+g^{N}_{R}\,\bar N\gamma^\mu P_R N
\;\Bigr] Z_{R\,\mu}.
$$

Points of precision:

* There is **no** right-handed light-neutrino term and **no** left-handed $N$ term — the
  light $\nu$ is purely left-handed and $N$ is purely right-handed, as expected.
* $\bar N\gamma^\mu P_R N$ with a Majorana $N$: the vector part cancels between the two
  Wick contractions, so the physical $Z_R N N$ vertex is **purely axial**, with an
  effective factor $2\times$ from the two identical fields.
* The current is diagonal in generation: $Z_R$ couples $N_1N_1$, $N_2N_2$, $N_3N_3$ only.
  No $N_iN_j$ ($i\neq j$) transition.

### 1.8 Total

$$
\mathcal{L}_{\rm total}=\mathcal{L}_{\rm SM}
+\mathcal{L}_{W_R}^{\rm kin}+\mathcal{L}_{Z_R}^{\rm kin}+\mathcal{L}_{N}^{\rm kin}
+\mathcal{L}_{W_R}^{q}+\mathcal{L}_{W_R}^{\ell}
+\mathcal{L}_{Z_R}^{q}+\mathcal{L}_{Z_R}^{\ell}.
$$

## 3. Parameters

### 3.1 External parameters

Both live in the Les Houches block `LRSMINPUTS`.

| symbol | block / order | value | interaction order | what it multiplies | physical meaning |
| --- | --- | --- | --- | --- | --- |
| `kapRq` ($\kappa_R^{\,q}$) | `LRSMINPUTS` 1 | 1. | `{NP,1}` | the overall factor of `LWRq` and `LZRq`; also appears inside `nZRq`, `gLZRu`, `gRZRu`, `gLZRd`, `gRZRd` | Ratio of the right-handed to the left-handed gauge coupling **in the quark sector**, $\kappa_R^{\,q}=g_R^{\,q}/g_L$. At the default value $g_R=g_L$ (manifest left–right symmetry). It carries the single unit of `NP` order, so every new vertex counts as NP=1. |
| `kapRl` ($\kappa_R^{\,\ell}$) | `LRSMINPUTS` 2 | 1. | `{NP,1}` | the overall factor of `LWRl` and `LZRl`; also appears inside `nZRl`, `gLZRe`, `gRZRe`, `gLZRv` | Same ratio **in the lepton sector**, $\kappa_R^{\,\ell}=g_R^{\,\ell}/g_L$. Splitting quark and lepton $\kappa$ lets quark-side and lepton-side $W_R/Z_R$ couplings be rescaled independently — the usual way to make an effective $W'/Z'$ fit a specific cross-section $\times$ branching ratio. |

All other masses and couplings ($g_L$, $s_W$, $c_W$) come from the SM file; `MWR`, `MZR`,
`mn1`, `mn2`, `mn3` and the widths are external by virtue of the `Mass`/`Width`
declarations in §2.

| `gRZRn` | $+\tfrac12$ | $Z_R$ charge of $N_R$ |
| `VCKMR` | $3\times3$, `Unitary -> True`, value $=\mathbb{1}$ | right-handed quark mixing matrix $V^R_{\rm CKM}$; identity at the default point (no right-handed flavour violation) |
| `YN` | $3\times3$, value $=\mathbb{1}$ | heavy-neutrino mixing in the $W_R$ lepton current; identity, so $N_i$ pairs with $\ell_i$ one-to-one |
| `XN` | $3\times3$, value $=0$ | light-neutrino mixing in the $W_R$ lepton current; zero, so $W_R\ell\nu$ is switched off at the default point |

**Check of the $Z_R$ charges.** Every entry is reproduced by

$$
g^{f}_{L,R}\;=\;T^{3R}_{f}\;-\;\frac{\tan^2\theta_W}{\kappa_R^{2}}\;Y_f ,
\qquad Q=T^{3L}+Y ,
$$

with $Y_{q_L}=\tfrac16$, $Y_{u_R}=\tfrac23$, $Y_{d_R}=-\tfrac13$, $Y_{\ell_L}=-\tfrac12$,
$Y_{e_R}=-1$, $Y_{N_R}=0$, and $T^{3R}=+\tfrac12$ for $u_R,N_R$, $-\tfrac12$ for
$d_R,e_R$, $0$ for all left-handed fields. This is exactly the standard $Z_R$ charge of an
$SU(2)_L\times SU(2)_R\times U(1)_{B-L}$ model after the $B-L$ charge is traded for $Y$.

### 3.3 Interaction-order hierarchy

`{{QCD,1},{QED,2},{NP,1}}` — the module adds a new coupling order `NP`, carried once by
each of $\kappa_R^{\,q}$ and $\kappa_R^{\,\ell}$, so every new-physics vertex is `NP=1`.

## 4. Physics summary

This is an **effective left–right-symmetric extension of the Standard Model**: it adds a
charged heavy vector $W_R$ (3 TeV, $Q=+1$), a neutral heavy vector $Z_R$ (5.07 TeV), and
three right-handed Majorana neutrinos $N_{1,2,3}$ (173.3 GeV, and two decoupled states at
$10^{12}$ GeV), coupled to the Standard Model by hand-written purely right-handed ($V+A$)
charged currents and by $Z_R$ neutral currents whose charges are $T^{3R}-\tan^2\theta_W
Y/\kappa_R^2$. Two external knobs, $\kappa_R^{\,q}$ and $\kappa_R^{\,\ell}$, rescale the
right-handed coupling in the quark and lepton sectors independently; at the default point
$g_R=g_L$, the right-handed CKM matrix is the identity, and light–heavy neutrino mixing
($X_N$) is zero.

It would mediate the classic left–right collider signatures: resonant $s$-channel
production $pp\to W_R\to \bar u d$ (dijet) and $pp\to W_R\to \ell^\pm N$ followed by
$N\to \ell^\pm jj$ through an off-shell $W_R$ — the Keung–Senjanović **same-sign
dilepton plus two jets** final state, which violates lepton number by two units because
$N$ is Majorana; plus $pp\to Z_R\to \ell^+\ell^-$, $\bar q q$, $\nu\bar\nu$ and $Z_R\to
NN$. Because no Higgs sector, no $W$–$W_R$ or $Z$–$Z_R$ mixing, and no Dirac neutrino mass
are included, the module describes only the gauge-current phenomenology of the heavy
sector, not the symmetry breaking or the seesaw that would generate it.

## 5. Notes and internal consistency flags

These are observations a checker should be aware of; they are properties of the file as
given, not corrections applied to the reconstruction above.

1. **No `CC` (charge conjugation) anywhere.** `NR` is `SelfConjugate -> True`, yet the
   $W_R$ lepton current is written as the plain bilinear
   `NRbar.YN.Ga[mu].ProjP.l` with only `HC` added. A left–right model with a Majorana $N$
   is often written with an explicit `CC` on one chirality projection so that both the
   $N\ell^-W_R^+$ and $N\ell^+W_R^-$ orientations appear with the intended relative
   phase; here the two orientations come only from `tmp + HC[tmp]`. If a charge-conjugated
   partner term was intended, it is absent.
2. **No gauge structure for the new vectors.** `FS` on `WR`/`ZR` is abelian, so there are
   no $W_RW_R\gamma$, $W_RW_RZ$, $W_RW_RZ_R$ or quartic gauge vertices, and no
   $W$–$W_R$ / $Z$–$Z_R$ mass mixing. Gauge-boson pair production of $W_R$ is therefore
   not described.
3. **No Higgs sector.** No bidoublet, no $SU(2)_R$ triplet. The $W_R$, $Z_R$ and $N$
   masses are put in by hand. $M_{Z_R}/M_{W_R}=1.69$ is consistent with the usual
   left–right relation at $\kappa_R\simeq1$, so the numbers were chosen to mimic a real
   breaking pattern.
4. **$X_N=0$ and $Y_N=\mathbb{1}$** mean the $W_R\,\nu\,\ell$ vertex vanishes and the
   $W_R\,N\,\ell$ vertex is flavour diagonal at the default numerical point. The $X_N$
   term in `LWRl` is present in the Lagrangian but generates no numerically non-zero
   vertex unless the user changes the matrix.
5. **`nZRq`, `nZRl` become imaginary** if $\kappa_R < \tan\theta_W \approx 0.55$; the
   model is only usable above that value.
6. **`mn2 = mn3 = 1.*^12` GeV with zero width** removes $N_2$, $N_3$ from any collider
   process; only $N_1$ is active.
7. In `LNkin` the local variable `sp` is declared and used only on the mass term; the
   kinetic term relies on implicit spinor contraction. This is harmless.

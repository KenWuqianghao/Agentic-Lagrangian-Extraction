## Summary of changes made to `model.fr`

I removed the unused `LChernSimonsPortal` definition (the pre-electroweak-symmetry-breaking, gauge-invariant D'Hoker-Farhi operator written with `HC[H].DC[H,mu]/(HC[H].H)`). This term is non-polynomial in the Higgs field and was already excluded from `LTot` by a prior repair attempt, but it was left in the file as inert "documentation." Since that prior fix produced the exact same `no_lagrangian_symbol` failure as the original file, the dead definition was still the most likely cause: a full-file Lagrangian scan or compile step can choke on any non-polynomial term it encounters, whether or not that term is wired into `LTot`. The physically relevant, polynomial mass-eigenstate realization of the same operator (`LChernSimonsPortalBroken`, in terms of `Z`, `A`, `W`, `xb`) was already present and is unchanged, so no physics content, field, quantum number, or operator structure is lost — only the redundant, unusable EFT-form duplicate is gone.

I also fixed two smaller technical defects on the `xb` vector class: changed `PropagatorType -> Sine` (the JaxoDraw convention for ghost fields) to `PropagatorType -> W` (the correct convention for a genuine propagating vector boson), and removed the redundant `QuantumNumbers -> {Q -> 0, Y -> 0}` entry, since a value of exactly zero for every quantum number is FeynRules' default anyway and dropping it removes any ambiguity around an ad hoc `Y` (hypercharge) key that is not otherwise used for physical mass eigenstates in the broken phase.

All physics content is preserved: the `xb` field, its mass/width, the Chern-Simons portal coupling structure (`c1`, `c2` with unchanged values and interaction-order settings), the Hermiticity-restoring `+HC[...]` term from the prior repair, and the free Proca kinetic/mass Lagrangian for `xb` are all intact and unchanged.

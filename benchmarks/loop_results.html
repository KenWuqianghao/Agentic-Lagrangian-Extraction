The binding constraint was diagnostic signal, not agent intelligence.

Each phase used the same repair agent, isolated the same way — no network, no reference files, no model name. Only the diagnostics improved. On the UFO-serialization class the agent scored 0 / 5 while working blind from a log tail; once the harness pinpointed the offending file and line, the same class became routine.

Taxonomy

Four kinds of defect

Reliably repairable

Visible in the FeynRules log

Syntax errors, undefined Lagrangian symbols, self-conjugate fields carrying quantum numbers, duplicate names — and above all namespace collisions. ClassName → N hit four models; a coupling named e collided with the electron field; an index named HC collided with FeynRules' own HC[] and caused a mystery 900 s timeout. The loop cleared every instance once the error text reached its report.

The blind class

UFO-serialization leaks

WriteUFO silently emits unevaluated Wolfram expressions into the UFO Python. Every FeynRules check passes; MadGraph then fails with one constant, misleading message. Seen: ReplaceAll leaks, [[..]] Part syntax, PRIVATE` internals, 2D-typeset exponents, $ in symbol names. Blind: 0 fixed. Pinpointed: routine.

Hard physics

Hermiticity residuals

SU(2)-multiplet covariant-derivative commutator residuals. Vertex-level check output helps — it cleared pSPSS in phase 2 — but does not guarantee convergence. SLQrules survived nine rounds unrepaired.

Generator-side

Structural defects

Multi-member ClassMembers scalar classes serialize to invalid UFO Python, and faithful restructuring exceeds the compile budget. Best fixed deterministically in the generator, not by a repair agent.

The part that still needs a physicist

Passing is not the same as correct

Passing means the tool chain accepts the model. It does not mean the physics matches the paper — every stage after extraction inherits the extraction's reading of it. So we ran the chain backwards: an agent that never saw the paper reconstructed the Lagrangian from the sanitized .fr alone, and a second fresh agent graded that reconstruction against the paper term by term.

Caveats

What this does not establish

  • The repair agent ran isolated, but the underlying model may have seen these public model files in training. Sanitizing removes the labels, not that risk.
  • Symbol names survive sanitizing on purpose — a reviewer needs them — so the blank-slate agent was not perfectly blind.
  • Repairs that replaced symbolic values with numerics keep the tool chain valid while narrowing the model's parameter generality. The analysis flags each one.
  • Three models were never recovered: ALRM_general, HNLs, SLQrules. They ship in the review bundle too, so the picture is not only the successes.

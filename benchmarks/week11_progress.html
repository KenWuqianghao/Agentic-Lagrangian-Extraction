HEPTAPOD · GSoC · Week 11

The exoplanet tools move to ASTER

A fair question — “but does it explain why?” — set the week's direction. Answering it honestly led to the people who own that question: the ASTER exoplanet toolkit. By the end of the week the measurement tools had migrated into ASTER with a pull request open, the toolbase pipeline was field-tested (two real bugs found) — and the “why” gap itself was closed: the bundle now follows disagreeing references to their papers and states how the analyses differ, and fetches archive transmission spectra ready for TauREx.

01 · The honest answer

Does the disagreement tool explain why?

No — and saying so precisely is what made the rest of the week possible. The tool finds every published parameter set for a planet, computes the worst pairwise tension in sigma, and attributes each value to its reference. For HD 189733 b that means 21 published sets and this pair:

referenceperiod (days)σbibcode
Kokori et al. 20232.2185749443.0e−082023ApJS..265....4K
Stassun et al. 20172.2185756701.5e−072017AJ....153..136S
tension4.7σ

What it does: quantifies that measurements disagree, by how much, and who published each value.

What it cannot do, as built: say why. The archive's ps table stores no per-measurement instrument and no observation epoch — the reason a paper got a different number lives in that paper's methods section. The tool already returns bibcodes, so the missing piece is a fetch-the-paper-and-read-the-methods step. That was the state at the start of the week; section 05 is the fix, built, verified live, and worked through step by step below.

02 · The right home

ASTER, and why the tools belong there

The astrophysicists connected this work to Emilie Panek, who maintains ASTER — the Agentic Science Toolkit for Exoplanet Research (arXiv:2603.26953), built on the same orchestral framework as heptapod. Her toolkit already queries the NASA Exoplanet Archive, but reads pscomppars: one composite row per planet. The measurement tools read ps: one row per published reference, which is the only table that can say two papers disagree. Complementary, not duplicate — and clearly ASTER's domain, not a particle-physics toolkit's.

Decision: migrate the whole bundle out of heptapod and into ASTER. A hard cutover — after the move, ASTER is the only home of these tools.

05 · The gap, closed

From “who disagrees” to “why they disagree”

The one handle a ps row gives is its bibcode, and it turns out to be enough — keyless end to end. ADS's public link gateway answers a bibcode with a redirect to the paper's arXiv page; arXiv's export API serves the title and abstract; a deterministic method taxonomy fingerprints what kind of analysis the abstract describes; and the tool states the difference between the two sides.

Worked example: one question, four tool calls

The question a referee would actually ask: “Papers quote different orbital periods for HD 189733 b — why?” Every value below is the live output of the migrated tools, recorded this week.

step 1 resolve_planet_name("HD189733b") Papers write the name without spaces; the archive does not. One candidate comes back — HD 189733 b — so the agent may proceed without asking.
step 2 measurement_disagreement("HD 189733 b") 21 published parameter sets. Worst tension: 4.7σ on pl_orbper, between Kokori et al. 2023 (2.218574944 ± 3.0×10⁻⁸ d) and Stassun et al. 2017 (2.218575670 ± 1.5×10⁻⁷ d). This tool stops here — that, how much, who — and its output now points to step 3 for the why.
step 3 explain_measurement_disagreement("HD 189733 b") Follows both bibcodes through the ADS link gateway to arXiv 2209.09673 and 1609.04389, fingerprints the abstracts, and answers — see the output below.
step 4 transmission_spectrum("HD 189733 b") If the follow-up is atmospheric work rather than ephemerides: the published spectrum, ready for a TauREx retrieval — summarized below.

      methods: transit timing / ephemeris monitoring, transit photometry

      methods: astrometry / parallax, radial velocity
      facilities: Gaia

“The two values come from different kinds of analysis. …When the
 method families differ, the disagreement usually traces to the data
 and technique each paper chose, not to an error either made.”

So the 4.7σ tension is not a mystery: one side is a dedicated multi-year transit-timing campaign, the other an empirical Gaia-parallax re-analysis. Two honesty rules are built in: when both abstracts describe the same kind of analysis, the tool says the difference lives in details abstracts do not carry and hands back the arXiv ids to read; when a paper has no arXiv eprint, it returns a reason and the ADS link — never a guess.

Until now this fetch needed a human: ASTER's DownloadDataset asks the user to click through the archive's Firefly page and paste wget commands. This tool reads transitspec over keyless TAP, so the agent gets the spectrum — with every point attributed to its instrument and paper — on its own.

## Summary of changes to `model.fr`

**Root cause 1 — undeclared multiplet fields.** The Lagrangian (`LQ2Phi`, `LQkin`, `LQf`, `LQ3Phi`, `LQ4Phi`) is written using SU(2) multiplet fields `S1`, `S1t`, `R2`, `R2t`, `S3` with explicit `SU2D`/`SU2W` indices, but `M$ClassesDescription` only declared their post-decomposition charge/mass eigenstates (`S1m13hat`, `R2p23hat`, `R2p53hat`, `R2tm13hat`, `R2tp23hat`, `S3m13hat`, `S3p23hat`, `S3m43hat`, `S1tm43hat`). FeynRules could not resolve the index structure of these undeclared symbols, producing the `Inner::incom: Length 2 ... {SU2D, Generation} is incommensurate with length 1 ... {Index[SU2D, 1]}` errors. Fix: added five `Unphysical -> True` field classes for `S1`, `S1t`, `R2`, `R2t`, `S3` with `Definitions` rules that alias each multiplet component to its already-declared physical field (singlets map 1:1; doublets map component-by-component; the triplet uses the standard `T±/T3` complex combination `S3[1]=(S3p23hat+S3m43hat)/√2`, `S3[2]=i(S3p23hat-S3m43hat)/√2`, `S3[3]=S3m13hat`, which I verified algebraically gives clean diagonal kinetic and mass terms). This is the same idiom FeynRules' own `SM.fr` uses for `W±` in terms of `W1,W2`. No Lagrangian expression itself needed to change — physics content, quantum numbers, and parameter values are all preserved exactly.

**Root cause 2 — Mathematica built-in collision.** `LQ2Phi` and `LQf` used bare `D`, `E`, `F` as SU(2) adjoint indices without localizing them in a `Module`, colliding with the protected system symbols `D` (derivative) and `E` (Euler's number) — this produced the `Global`D$...::shdw` / `Global`E$...::shdw` warnings and the `Sum::vloc`/`$Aborted` crash. Fix: wrapped `LQ2Phi` in `Module[{D,E,F}, ExpandIndices[..., FlavorExpand -> {SU2D, SU2W}]]` (matching the style already used by `LQ3Phi`/`LQ4Phi`), and added the missing `D` to `LQf`'s existing `Module[{i,j,a,b,c,...}]` local list.

**Root cause 3 — broken template residue.** `LQ4Phi` contained three `Sum[...]` terms referencing completely undeclared fields (`Phia`, `PhiA`, `Phib`) and undeclared parameters (`Ya1`, `Yab1`, `Yprimeab1`, `Ya3x3`, `Yprimea3x3`), with malformed iterator syntax that reused the loop letter `a` as both a species-loop index and the `Ta[D,a,b]` SU(2) index — the direct cause of the `Sum::vloc: FieldExpand[a$18429] cannot be localized` errors. These terms are unambiguous leftover artifacts (no such fields/parameters exist anywhere else in the file), while the corresponding real quartic self- and cross-couplings for `R2`, `R2t`, `S3` are already correctly present elsewhere in `LQ4Phi` via the properly declared `Y2x3`, `Y2tx3`, `Y3x3`, `Y3x5`, `Y2t2x3`/`Yprime2t2x3` terms. I removed the three broken terms (and their connecting `+`) rather than fabricate new physics content for undefined fields.
